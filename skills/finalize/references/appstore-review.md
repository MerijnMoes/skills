# App Store review

Use this specialty reference when the diff touches iOS metadata, purchases,
privacy disclosures, or reviewer-facing submission/setup surfaces.

- Scope: App Store-sensitive metadata, entitlement/purchase descriptions,
  privacy disclosures, and reviewer instructions affected by the diff.
- Scope: whether Phase 5 docs or release notes need submission-facing updates.
- Scope: compact routing and findings only; later tasks may expand the actual
  review checklist content.
- Mutability mode: `report-first`
