# Architecture docs review

Use this specialty reference when the diff changes a public API or architecture
boundary and the finalize pass needs to assess architecture-facing docs.

- Scope: public interfaces, boundary contracts, layering changes, and
  architecture notes or diagrams that may now be stale.
- Scope: whether the change should produce a doc/update finding versus a Phase
  5 documentation action.
- Scope: deliberately minimal router; later tasks may expand the detailed
  checklist content.
- Mutability mode: `small-fix-allowed`
