# Accessibility review

Use this specialty reference when the diff changes user-facing UI or markup
that deserves a dedicated accessibility lane in Phase 4.

- Scope: accessibility-sensitive UI structure, semantics, keyboard behavior,
  focus order, and text alternatives touched by the diff.
- Scope: verification expectations that should later connect to the main
  Phase-6 accessibility check rather than creating a separate verification
  system here.
- Scope: compact findings and lane-registration metadata only; later tasks may
  expand this reference with deeper review prompts.
- Mutability mode: `report-first`
